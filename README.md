# VIE Group Website

Modern GitHub Pages remake of the VIE Group website.

## Local Preview

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`.

## Content

- Source of truth: `vie-group/vie-group-content`.
- Local mirror: `data/*.json`, synced from `vie-group-content` for static legacy pages and RSS.
- `media/`: recovered files from the old `vie.group` site.
- `content-source.json`: content repository and raw asset URL configuration.

The modern front page reads JSON from `vie-group-content` at runtime and falls back to the local `data/` mirror. Legacy static pages are regenerated from the local mirror by the content sync workflow.

## Maintenance

- Teacher publication editor: `admin.html#publication`
- Student seminar upload without token: `upload-seminar/` -> `vie-group-content` issue with image/PPT/PDF attachments -> workflow-localized files under `vie-group-content/assets/seminars/`
- Student seminar delete without token: `vie-group-content` issue template `Delete seminar submission` -> same-author ownership check -> content PR
- Activity detail archive: `data/activity-details.json` regenerated by `npm run archive:activity`
- Admin direct seminar upload: `admin.html#seminar`
- Content sync: `.github/workflows/sync-content.yml`

Detailed operating notes are in `docs/maintenance.md`.

## Validation

```bash
npm run validate
```

The validation workflow also runs on pull requests and pushes to `main`.

To retry archived-file recovery:

```bash
npm run download:wayback
```
